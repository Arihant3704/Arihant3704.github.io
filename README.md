# Arihant3704.github.io

Welcome to my personal portfolio website! This site showcases my skills, projects, and background as a developer.

## 🌟 About This Portfolio

This repository contains the source code for my portfolio, built to represent my professional profile online. Here, you can learn more about me, explore my featured projects, and find ways to connect.

## 🚀 Features

- Personal introduction
- Project highlights with descriptions and links
- Overview of technical skills
- Contact information for collaboration
- Inline playable previews for selected UAV and robotics simulations, with links to the full telemetry dashboard
- A dismissible full-HUD prompt shown after the Simulation Lab, plus interactive 3D preview-card tilt on fine pointers
- Clickable competition photos that open in an accessible, keyboard-dismissible full-size image viewer
- Persistent light/dark themes, motion-aware transitions, and a pointer-follow effect on mouse devices

## 🛠️ Tech Stack

- HTML5, CSS, and JavaScript

## 📁 Project Structure

- `assets/css/` — portfolio, simulation, and shared UI styles
- `assets/js/` — portfolio, simulation, and shared UI behavior
- `assets/research/certificates/` — research publication certificates
- `images/`, `videos/`, and `certificates/` — portfolio media and credentials
